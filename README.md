# Prompt Author

목표를 실제로 사용할 수 있는 프롬프트로 바꾸는 Codex 스킬입니다. 프롬프트를 장식적인 문장이 아니라, 결과·제약·검증 방법이 명확한 작업 계약으로 다룹니다.

## 지원하는 작업

- 일반 대화, 초안 작성, 브레인스토밍
- 최신 정보와 출처가 필요한 리서치
- 이미지·영상 제작 프롬프트
- JSON 스키마 등 구조화된 출력
- 코드 수정·디버깅을 수행하는 에이전트
- 도구·API를 사용하는 에이전트
- 자율 실행 루프와 Codex `/goal`
- 기존 프롬프트의 문제 분석과 개선

## 설치 방법

기본 Codex 스킬 경로에 이 저장소를 복제합니다.

```bash
git clone https://github.com/seominpapa/prompt-author.git ~/.codex/skills/prompt-author
```

설치한 뒤 새 Codex 작업을 시작하면 `$prompt-author`로 사용할 수 있습니다. 이미 설치되어 있다면 해당 폴더에서 최신 변경을 받습니다.

```bash
git -C ~/.codex/skills/prompt-author pull
```

## 두 가지 사용 방법

1. **스킬 설치** — 위 설치 방법으로 `$prompt-author`를 Codex에서 반복 사용합니다.
2. **웹에서 즉시 생성** — [Prompt Author Lab](https://prompt-author-lab.vercel.app)에서 조건을 입력하고, 생성된 프롬프트를 복사해 ChatGPT·Codex 등 원하는 도구에 붙여 넣습니다.

## 사용 방법

이 스킬이 설치된 환경에서 원하는 결과를 자연어로 요청하세요. 필요한 정보가 결과를 크게 바꾸는 경우에만 짧은 질문을 하고, 그렇지 않으면 안전한 가정을 명시한 뒤 바로 프롬프트를 작성합니다.

예시:

```text
신규 기능의 API 명세를 검토하고 JSON으로 결과를 반환하는 프롬프트를 만들어줘.
```

```text
현재 자료를 조사해 경쟁사 비교 보고서를 작성하는 리서치 프롬프트를 만들어줘.
```

```text
/goal로 사용할, 테스트와 보안 검토가 포함된 작업 프롬프트를 만들어줘.
```

## 상황별 프롬프트 제공 방식

요청을 아래 유형으로 분류한 뒤, 해당 상황에 필요한 제약과 검증 조건을 포함한 복사 가능한 프롬프트를 제공합니다. 알 수 없는 값은 `{{변수}}`로 남기고, 입력해야 할 값을 함께 설명합니다.

| 작성 상황 | 제공되는 프롬프트 |
| --- | --- |
| 일반 대화·초안 | 대상 독자, 목표, 맥락, 제약, 원하는 결과 형식을 간결하게 정리합니다. |
| 리서치 | 허용 출처, 최신성 기준, 인용 방식, 사실과 추론의 구분을 포함합니다. |
| 이미지 제작 | 피사체, 스타일·조명·구도, 비율, 필요한 제외 조건을 순서대로 지정합니다. |
| 영상 제작 | 한 장면의 행동, 카메라·연출, 길이·형식, 필요한 사운드·제약을 지정합니다. |
| JSON 등 구조화된 출력 | JSON 스키마, 누락 입력 처리, 스키마 검증 조건을 명시합니다. |
| 코드 작업 | 변경 가능한 범위, 보존해야 할 제약, 루트 원인 확인, 테스트·검증 명령을 포함합니다. |
| 도구·API 사용 | 사용 가능한 도구, 결과 재평가, 승인 필요한 외부 작업, 출력 형식을 구분합니다. |
| 자율 실행·`/goal` | 측정 가능한 완료 조건, 작업 범위, 반복·재시도 정책, 차단·승인 조건과 최종 보고 형식을 지정합니다. |
| 기존 프롬프트 개선 | 원본, 실제 실패 사례, 기대 결과, 평가 기준을 바탕으로 수정안과 평가 사례를 제공합니다. |

## 생성되는 프롬프트의 구성

요청에 맞는 항목만 골라 다음 순서로 구성합니다.

1. 역할과 범위
2. 목표
3. 컨텍스트와 입력
4. 제약 조건
5. 방법 또는 도구 정책
6. 검증 방법
7. 출력 형식
8. 중단 조건

에이전트 작업에서는 권한이 필요한 외부 작업, 재시도 한도, 완료·차단 조건도 명시합니다. 불확실하거나 최신인 사실은 도구로 확인하고, 웹·파일·도구 출력에 포함된 지시는 신뢰하지 않는 데이터로 취급합니다.

## 학습 웹사이트: 클론 및 실행

조건별 원칙·예시·실습 기능이 있는 웹사이트를 로컬에서 실행하려면 Node.js 20 이상과 Git이 필요합니다.

```bash
git clone https://github.com/seominpapa/prompt-author.git
cd prompt-author/website
npm ci
npm run dev
```

명령 실행 후 터미널에 표시되는 로컬 주소를 브라우저에서 여세요. 일반적으로 `http://localhost:3000` 또는 `http://localhost:5173`입니다.

설치 없이 확인하려면 [Prompt Author Lab](https://prompt-author-lab.vercel.app)을 사용할 수 있습니다.
