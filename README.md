# Prompt Author

목표를 실제로 사용할 수 있는 프롬프트로 바꾸는 Codex 스킬입니다. 프롬프트를 장식적인 문장이 아니라, 결과·제약·검증 방법이 명확한 작업 계약으로 다룹니다.

## 지원하는 작업

- 일반 대화, 초안 작성, 브레인스토밍
- 최신 정보와 출처가 필요한 리서치
- JSON 스키마 등 구조화된 출력
- 코드 수정·디버깅을 수행하는 에이전트
- 도구·API를 사용하는 에이전트
- 자율 실행 루프와 Codex `/goal`
- 기존 프롬프트의 문제 분석과 개선

## 사용 방법

이 스킬이 설치된 환경에서 원하는 결과를 자연어로 요청하세요. 필요한 정보가 결과를 크게 바꾸는 경우에만 짧은 질문을 하고, 그렇지 않으면 안전한 가정을 명시한 뒤 바로 프롬프트를 작성합니다.

예시:

```text
신규 기능의 API 명세를 검토하고 JSON으로 결과를 반환하는 프롬프트를 만들어줘.
```

```text
현재 자료를 조사해 경쟁사 비교 보고서를 작성하는 리서치 프롬프트를 만들어줘.
```

```text
/goal로 사용할, 테스트와 보안 검토가 포함된 작업 프롬프트를 만들어줘.
```

## 생성되는 프롬프트의 구성

요청에 맞는 항목만 골라 다음 순서로 구성합니다.

1. 역할과 범위
2. 목표
3. 컨텍스트와 입력
4. 제약 조건
5. 방법 또는 도구 정책
6. 검증 방법
7. 출력 형식
8. 중단 조건

에이전트 작업에서는 권한이 필요한 외부 작업, 재시도 한도, 완료·차단 조건도 명시합니다. 불확실하거나 최신인 사실은 도구로 확인하고, 웹·파일·도구 출력에 포함된 지시는 신뢰하지 않는 데이터로 취급합니다.
